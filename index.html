    LOCAL DATA & BACKUP

    데이터 백업 · 관리

    컴퓨터를 종료해도 저장한 자료가 남도록 관리합니다. 실행 중 약 5분 간격으로 자동 백업을 갱신합니다.

    ▣

    내 PC에 저장됩니다

    PC의 고정 저장 폴더에 data 폴더가 자동으로 만들어집니다.

    %LOCALAPPDATA%/HDC_Permit_Review/data/permit_review.sqlite3 요청서 · 검토결과 · 이력
    data/attachments/ 사진 · 도면 · PDF 실제 파일

    프로그램을 종료했다가 다시 실행해도 자료가 유지됩니다. 다만 고정 저장 폴더의 DB와 파일을 삭제하면 자료를 잃을 수 있습니다.

    ⇩

    백업 파일 받기 · 자동 백업

    요청서 DB와 첨부파일을 하나의 ZIP 파일로 다운로드합니다. 자동 백업본은 PC의 data/auto_backups에 날짜별로 최대 7개까지 보관되며, 실행 중 약 5분마다 당일 백업을 갱신합니다.

    중요: ZIP 백업은 이 PC뿐 아니라 회사가 승인한 별도의 저장 위치에도 보관하세요.

    회사 서버로 이전할 때

    백업 ZIP에는 SQLite DB와 첨부파일이 함께 담깁니다. 서버 도입 시 IT 담당자에게 전달해 정식 인증·권한관리·메일 연동을 추가한 후 이관할 수 있어요.

    ⚠ 현재 PC 데이터는 로그인 보호·암호화·접근기록 체계를 갖춘 운영 시스템이 아닙니다. 기밀 도면이나 실제 개인정보를 넣기 전 회사 IT·보안 담당자와 승인 범위를 확인하세요.
