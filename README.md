# 대외협력팀 인허가 검토관리

현재 웹 화면 테스트용 파일이 `docs/index.html` 에 준비되어 있습니다.

## GitHub Pages 화면 시연
- 시험용 HTML: `docs/index.html`
- GitHub의 **Settings → Pages → Build and deployment → Deploy from a branch** 에서 `main` / `/docs` 를 선택하고 저장하면, GitHub Pages가 허용된 계정에서 웹주소를 발급받을 수 있습니다.
- 이 저장소는 현재 **Private** 입니다. GitHub Free에서는 Private 저장소의 GitHub Pages가 지원되지 않습니다. 저장소를 공개로 전환하면 전체 소스코드도 공개되므로 회사 승인 없이 변경하지 마세요.

### 꼭 알아둘 점
현재 `docs/index.html`은 **기존 화면·접수·검토 동선을 보여주는 브라우저 시연용** 입니다. 테스트 데이터는 브라우저 세션에만 저장됩니다. **다른 직원과 공유되는 실제 접수·회신 서버는 아직 구축되지 않았습니다.** 시연용 자료만 입력하세요. 기존 V9.3 완전 기능 이관은 별도 개발 단계입니다.
